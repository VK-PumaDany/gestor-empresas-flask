Instalación

Tener instalado pyton en su version > Python 3.13.7 o superior
Instalar con pip > pip install virtualenv
Iniciamos el entorno virtual > python -m virtualenv -p python3 env
Ingresamos en el entorno virtual > .\env\Scripts\activate
Descargamos Flask > pip install flask
Iniciamos el server con > python .\app\app.py

Código | archivo en la raiz app.py

from flask import Flask, render_template app = Flask(__name__) @app.route("/") def index(): return "Bienvenido" if __name__ == "__main__": app.run(debug=True, port=5000)

Para Iniciar:

py .\app.py
