# NOTAS PARA INICIAR EL PROYECTO DE PYTON

## Lista

- Tener instalado pyton en su version
  > **Python 3.13.7 o superior**
- **Instalar con pip:**
  > pip install virtualenv
- **Iniciamos el entorno virtual**
  > python -m virtualenv -p python3 env
- **Ingresamos en el entorno virtual**
  > .\env\Scripts\activate
- **Descargamos Flask**
  > pip install flask
- **Iniciamos el server con**
  > python .\app\app.py
